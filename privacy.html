Политика конфиденциальности

Эта политика описывает локальное приложение YouTube Shorts Uploader и его информационный сайт. Приложение поддерживается пользователем theporocenok.

Какие данные используются

Приложение получает через Google OAuth токены доступа и обновления, ID и название выбранного YouTube-канала, ID загруженных видео, сведения об их обработке, доступности и расписании. Для загрузки оно читает выбранные вами локальные видео, общую обложку, название, описание и даты публикации.

Вход выполняется на странице Google в браузере. Приложение не получает пароль Google, коды двухфакторной аутентификации или файлы сессии браузера.

Для чего нужен доступ

Данные используются для привязки нужного канала, загрузки выбранных материалов, установки обложек и расписания, проверки результата и продолжения прерванной загрузки. Запрашивается разрешение https://www.googleapis.com/auth/youtube.force-ssl. Оно включает более широкие возможности управления YouTube, в том числе комментариями, однако приложение использует только функции работы с каналом, видео и обложками.

Данные Google не используются для рекламы, продажи, профилирования или обучения моделей ИИ. Использование и передача сведений, полученных через Google APIs, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Где хранятся данные

Токены и адреса возобновляемой загрузки сохраняются на компьютере в зашифрованном виде с помощью Windows DPAPI текущего пользователя. Конфигурация OAuth-клиента, сведения о канале, журнал партии, контрольные суммы файлов, ID видео и отчёты также хранятся локально. Исходные видео, изображения, текстовые файлы и обычные метаданные журнала приложение дополнительно не шифрует.

Материалы и необходимые параметры отправляются напрямую Google/YouTube по HTTPS. У разработчика нет отдельного сервера, который принимает ваши видео или токены. Загруженные видео и расписание сохраняются у YouTube и обрабатываются по правилам Google.

Срок хранения и удаление

Локальные данные остаются до их удаления пользователем. Приложение не устанавливает автоматический срок очистки. После остановки скрипта можно удалить локальные файлы авторизации, конфигурацию и журналы, а также выбранные исходные материалы. При удалении журнала партии теряется информация, необходимая для безопасного продолжения загрузки; сначала проверьте результат в YouTube Studio.

Отозвать доступ можно в разделе подключений Google-аккаунта. После отзыва удалите локальный файл токена .local/token.dpapi. Новая работа с API потребует повторного входа.

Удаление локальных данных или отзыв доступа сами по себе не удаляют уже загруженные видео и не отменяют сохранённое в YouTube расписание. Управляйте этими материалами и датами в YouTube Studio.

Информационный сайт

Эти страницы размещаются на GitHub Pages. В них нет форм входа, собственных файлов cookie, рекламных скриптов или аналитики приложения. При посещении сайта GitHub может обрабатывать технические сведения о запросе, в том числе IP-адрес, согласно политике GitHub. Переходы на сайты Google и GitHub регулируются политиками этих сервисов.

Вопросы и изменения

Связь с поддерживающим приложение пользователем: GitHub Issues. Не публикуйте там токены, JSON авторизации, пароли, журналы с личными данными или приватные видео. При изменении обработки данных эта политика должна обновляться.
